# Distribution model

OpsAtlas uses a public, source-available portfolio model. It is visible for
technical review without being released as open-source software.

## What people can receive

- public access to inspect and fork the repository on GitHub; and
- permission to run an unmodified copy for personal, non-commercial evaluation.

## What people do not receive

- permission to modify or create derivatives;
- permission to redistribute, sublicense, rebrand, or claim ownership; or
- permission to sell OpsAtlas or use it inside a paid competing product.

The Git repository may remain public for recruiter and engineering review.
Every permitted fork or copy must retain `LICENSE` and `NOTICE`.

Copyright and contract terms discourage and provide remedies for misuse, but no
licence can make copying technically impossible. Before selling access or
providing binaries to customers, have the terms reviewed for the relevant
country and delivery model.
