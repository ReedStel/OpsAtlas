# Contributing

OpsAtlas is publicly viewable as a portfolio project but is not accepting code
contributions. Access to this repository does not grant permission to modify,
redistribute, rebrand, or sell its contents beyond the limited rights in LICENSE.

Authorised collaborators should use a short-lived branch, keep one concern per
commit, add tests for behavioural changes, and avoid real infrastructure data in
fixtures, screenshots, issues, or commit messages. Never commit `.env` files,
credentials, customer names, internal host names, or production telemetry.
